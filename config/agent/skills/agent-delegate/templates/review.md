# Review (blind, non-author)

```text
Goal: review <diff/files> for <correctness / security / conventions>.
Context: <requirements only — no author rationale, suspected bugs, or preferred
outcome, and no unrelated conversation history>.
Scope: read-only.
Acceptance: each finding has severity, file:line, and a concrete failure
scenario or violated rule. "No findings" is valid.
Report: findings by severity, one-line verdict, confidence, and unchecked areas.
Do not spawn or delegate to another agent unless the lead explicitly authorizes
nested delegation.
```
